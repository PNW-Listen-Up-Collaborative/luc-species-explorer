# Handoff: LUC Species Detection Explorer (BirdNET Dashboard)

## Overview
A single-page analytics dashboard for exploring a BirdNET acoustic species-detection dataset (~145k rows) across preserves, plots, treatment regimes, and time. Users filter the dataset with a toolbar of controls, then flip between five chart types (Trends, Species, Diversity, Occupancy, Region) and an optional "Compare by" grouping that splits the Trends/Diversity charts into multiple colored series.

**Target environment:** Streamlit, deployed from GitHub via Streamlit Community Cloud. Build with `st.columns`/`st.container` for layout, `st.multiselect`/`st.select_slider`/`st.segmented_control` (or `st.radio` styled as pills) for filters, and Plotly (`st.plotly_chart`) or Altair for the charts — not raw HTML/CSS.

## About the Design Files
The bundled `BirdNET Detection Explorer.dc.html` (+ `modernist.css`) is a **clickable HTML design reference**, not production code. It runs entirely in-browser on ~4,300 rows of **synthetic** data generated by a seeded hash function — it does not read your real CSVs. The task is to **recreate this design and its interactions in Streamlit**, using Streamlit's own widget set and a real pandas-based data pipeline, following the layout/behavior/visual spec below. Do not attempt to port the HTML/JS directly — treat it as the source of truth for what the UI should look like and do, and reimplement it idiomatically in Python.

## Fidelity
**High-fidelity.** Colors, spacing, typography, and interaction behavior below are final. Reproduce them as closely as Streamlit's component set allows; where Streamlit can't match exactly (e.g. no native flush-left segmented control), get as close as possible and note the deviation.

## Screens / Views
This is a single screen with a static frame and a dynamic content panel that swaps by "Graph type."

### Frame (always visible)
1. **Header** — full width, bottom border 2px solid `#e3e0e0` (design system divider). Left: title "LUC Species Detection Explorer" (28px, heading font, weight 800, tracked tight) + a one-line subtitle summarizing active filters (e.g. `Conf ≥ 0.5 · 2022–2026 · 3/3 preserves · 12 plots`). Right: two buttons — "Download CSV" (secondary) and "Copy view link" (primary, filled with the accent color, label reads "Copied ✓" for 1.6s after click).
2. **"Select Parameters" section label** — bold 16px heading, sits above the filter toolbar.
3. **Filter toolbar** — a horizontal, wrapping row of filter groups (NOT a sidebar). Each group is a small vertical stack: an 10.5px uppercase tracked label, then the control. Groups, left to right:
   - **Species code** — button showing "Species (n/8)" that opens a checklist popover (checkboxes, one per species code + common name, plus "All"/"None" buttons).
   - **Year range** — two native selects ("from" / "to"), years 2022–2026, constrained so from ≤ to.
   - **Season** — multi-select pill/chip group (Spring/Summer/Winter), toggle by clicking.
   - *(divider)*
   - **Preserve** — checklist popover like Species (3 preserves).
   - **Plot** — checklist popover, options **cascade**: only plots belonging to currently-selected preserves are offered; toggling a preserve off removes its plots from the selection automatically, toggling it on adds all its plots.
   - *(divider)*
   - **Treatment group** — single-select segmented control: control / pretreat / posttreat / treat (pretreat+posttreat combined) / all.
   - **Treatment type** — multi-select pill group: Burn / Graze / Mow / Reference.
   - **Confidence** — single-select segmented control: 0.3 / 0.5 / 0.7 / 0.9 (detection = 1 where confidence ≥ threshold, else 0 — this threshold is applied by scaling a precomputed detection count, not literally re-thresholding raw scores; in the real pipeline this should be a genuine per-row confidence filter).
   - **Reset** button, pinned right, clears all filters to defaults.
4. **KPI row** — 5 equal-width cards in a strip with 2px dividers between them: Total detections, Species richness (of 8 tracked), Active plots (of N preserves), Detections/plot (mean), Top species (code + common name). Card label is small/uppercase/bold in the accent color; value is large (28px) bold heading; sub-line is 11.5px muted gray.
5. **Graph type / Compare by row** — two labeled control groups side by side:
   - **"Graph type"** — segmented control, options: Trends / Species / Diversity / Occupancy / Region.
   - **"Compare by"** — segmented control, options: None / Treatment group / Treatment type / Preserve / Forage guild. Only affects Trends and Diversity (see below).
6. **Chart panel** — bordered card containing a title + subtitle (changes per graph type), an optional legend (swatch + label + running total per series), and the chart itself.
7. **Footer build note** — dismissible-in-code informational strip, can be omitted in production.

### Chart types (driven by "Graph type")
- **Trends** — line chart, x = year+season buckets (e.g. `Sp'22`, `Su'22`, `Wi'22`...), y = summed detections. One line per Compare-by group (or a single line if "None"), with a filled area under each line at ~8% opacity, circular point markers with tooltips.
- **Diversity** — same line-chart shape, y = distinct species count (richness) per bucket instead of detections.
- **Species** — bar chart, one bar per species code, sorted descending by total detections, value label above each bar.
- **Occupancy** — a heatmap: rows = species codes, columns = year+season buckets, cell = "% of days/hours a species was detected" (0–100), cell background is the accent color at opacity scaled to the value (darker/more saturated = higher occupancy, white text once >50%). A "SAMP." row above the species rows shows sampling-effort (days sampled) per column, shaded in neutral ink instead of accent. A **Daily % / Hourly %** segmented toggle (top-right of the chart header) switches the underlying granularity — swapping both the metric definition and the panel title/subtitle. A low→high gradient legend bar sits below the grid.
- **Region** — a schematic (non-geographic) map: one dashed box per preserve, positioned via a fixed percentage layout; inside each box, one node per plot, shaded by species-richness-at-that-plot (accent opacity scale), showing plot ID and "n/total sp" count. A caption notes this is schematic and should be swapped for a real basemap once GPS/GeoJSON is available.

Compare-by grouping (Trends/Diversity only): None (single series) / Treatment group (control, pretreat, posttreat — fixed order, fixed colors) / Treatment type / Preserve / Forage guild (alphabetical, palette-cycled colors).

## Interactions & Behavior
- All filter controls are client-side state; every change re-filters the full row set and recomputes cards + the active chart synchronously (no loading spinner needed at this data size; add one once wired to the real 145k-row source if latency appears).
- Species/Preserve/Plot use a **button that opens a checkbox popover** (not native `<select multiple>`), so long lists don't consume toolbar width. Clicking anywhere outside a popover, or the button again, closes it. Only one popover open at a time.
- Preserve ↔ Plot cascade: selecting/deselecting a preserve adds/removes its plots from the Plot selection; this must stay bidirectionally consistent.
- Segmented controls (Confidence, Treatment group, Graph type, Compare by, Daily/Hourly) are single-select, filled with the accent color when active.
- Pill/chip groups (Season, Treatment type) are multi-select toggles, filled with the accent color when active.
- "Copy view link" copies the current filter/view state as JSON to the clipboard and shows "Copied ✓" for ~1.6s, then reverts.
- "Download CSV" exports whatever is currently on screen (the visible chart's rows), not the full dataset — column shape depends on the active graph type (see JS `downloadCsv` in the source file for exact per-view column layouts).
- **No-data state**: if the current filter combination yields zero detections, the chart area shows a centered empty-state message instead of a chart.
- **Reset**: restores all filters to defaults (full year range, all seasons/species/preserves/plots/treatment types, confidence 0.5, no treatment-group restriction, daily granularity) in one action.

## State Management
Minimum state needed (see the DC's `state` object in the source for the reference shape):
- `confidence: float` (one of 0.3/0.5/0.7/0.9)
- `yearFrom, yearTo: int`
- `seasons: string[]` (Spring/Summer/Winter)
- `species: string[]` (selected species codes)
- `preserves: string[]`, `plots: string[]` (plots cascade from preserves)
- `treatmentGroup: 'control'|'pretreat'|'posttreat'|'treat'|'all'`
- `treatmentTypes: string[]` (Burn/Graze/Mow/Reference)
- `graphType: 'trends'|'species'|'diversity'|'occupancy'|'region'`
- `compareBy: 'none'|'treatment_group'|'treatment_type'|'preserve'|'guild'`
- `occGranularity: 'daily'|'hourly'`
- `openDropdown` (UI-only, which popover if any is open)

**Data requirement:** the real dataset needs, at minimum, columns for year, season, species_code, species_common_name, foraging_guild, preserve, plot_id, treatment_group, treatment_type, confidence_score, and a detection flag/count. Pre-aggregate (year × season × plot × species) once at load time so every filter change is just a pandas groupby/filter, not a scan of all 145k rows.

## Design Tokens
Pulled from the Modernist design system (`modernist.css` — bundled) with one project-level override:
- **Accent (overridden to blue):** `#138eec` — this is a live/tweakable value in the design tool; hardcode it as the app's primary accent. Derived tints used for multi-series charts: a light tint (~`#8fcaf5`, +55% toward white) and a dark shade (~`#0b5599`, −40% toward black) — regenerate these from whatever final accent is chosen using a simple lighten/darken blend, don't hand-pick unrelated colors.
- **Ground/background:** `#f3f2f2` · **Text/ink:** `#201e1d` · **Neutral muted text:** `#7d7979` · **Divider/border:** `#e3e0e0` (2px rules throughout, never hairline)
- **Radius:** 0 everywhere — no rounded corners.
- **Fonts:** Archivo for both heading and body (weight 800 for headings/labels, 600 for pill/segment labels, 400 for body copy).
- **Type scale used:** 26–28px page title/KPI values, 19px panel title, 16px section label, 12.5–13px controls/body, 11–11.5px meta/sub text, 10–10.5px micro-labels (uppercase, letter-spacing ~0.08–0.1em).
- **Spacing:** 4/8/12/16/24/32px scale (design system `--space-*`), used consistently for gaps/padding.
- **Shadows:** only on the filter popovers (medium elevation), everything else is flat with border rules instead of shadow.
